## Regla común de edición concurrente
Cinco agentes en paralelo. Cada uno toca SOLO sus rutas. `packages/shared/src/index.ts`: agregar exports con una línea nueva al final (`echo "export * from './x.js';" >> …`) tras releer el archivo; nunca reescribirlo. ## A. Consola Claude (agente "consola")
Rutas: `packages/studio-mcp/**`, `.mcp.json` (raíz), `CLAUDE.md` (raíz), `apps/api/src/console/**` + `apps/api/src/routes/console.ts`, `apps/web/src/components/panels/ConsolePanel.tsx` + `apps/web/src/stores/console-store.ts` + registro del panel, `scripts/windows/**`, `docs/CONSOLA-CLAUDE.md`.
- **PTY**: la API expone `GET /api/console/ws` (WebSocket, solo 127.0.0.1, token de sesión emitido por `POST /api/console/session`) que lanza `claude` (Claude Code CLI) con `node-pty` en la raíz del repo, con `cwd`, `env` (sin keys), tamaño de terminal; `POST /api/console/resize`; cierre limpio. Si `claude` no está en PATH → mensaje con instalación (`npm i -g @anthropic-ai/claude-code`) y, si no hay login, mostrar que corra `claude auth login` en la propia terminal.
- **Web**: panel "Consola Claude" (dockview, atajo `Ctrl+Shift+C`) con xterm.js + fit addon, botón "Nueva sesión", estado (instalado / logueado / corriendo), chips de prompts sugeridos que se pegan en la terminal ("Analizá el video de referencia y proponé un perfil de estilo", "Cortá los silencios y exportá para Reels", "Redactá un reporte del último error").
- **MCP** (`packages/studio-mcp`, TypeScript, `@modelcontextprotocol/sdk`, stdio): herramientas que llaman a la API local (`http://127.0.0.1:3001`): `studio_get_project`, `studio_list_assets`, `studio_read_transcript`, `studio_propose_plan {command}`, `studio_validate_plan {plan}`, `studio_apply_plan {planId, confirmedIndexes}`, `studio_run_job {type, payload}`, `studio_get_job {id}`, `studio_wait_job {id}`, `studio_export {preset}`, `studio_preview_frame {t} → PNG path`, `studio_style_analyze {assetId}` / `studio_style_save_preset {preset}` / `studio_style_apply {presetId}` (contratos en B), `studio_bug_report {...}`, `studio_search_library {q}`. Cada herramienta devuelve JSON compacto y rutas de archivo cuando hay imágenes. `.mcp.json` registra `studio-mcp` con `node packages/studio-mcp/dist/index.js`.
- **CLAUDE.md** (raíz, español): qué es Studio, cómo usar las herramientas MCP, reglas (confirmar borrados/exportaciones, no tocar `storage/` a mano, no leer `.env`), flujos típicos, cómo analizar un video de referencia (ver hoja de contactos + análisis) y devolver un `StylePreset` con `studio_style_save_preset`.
- **Instalación**: `setup.ps1` paso opcional `-WithClaude` (default ON si Node ≥ 22): `npm i -g @anthropic-ai/claude-code`; `doctor.ps1` muestra versión y si hay login (`claude auth status` o equivalente documentado). Sin API key en ningún lado.

## B. Perfil de estilo (agente "estilo")
Rutas: `apps/workers/studio_workers/style/**` + `routers/style.py` + packs `ocr` (rapidocr-onnxruntime, Apache-2.0, opcional) y `vision-llm` (Ollama `qwen2.5vl:3b`, Apache-2.0, opcional), `packages/shared/src/style.ts`, `apps/api/src/routes/style.ts` + `jobs/handlers/style.ts` + `services/style/**`, `apps/web/src/components/panels/StylePanel.tsx` + `stores/style-store.ts` + registro, `docs/trabajo/modulo-sprint3b-estilo.md`.
- Workers `POST /style/analyze {path, max_frames?: 24}` → task → `StyleAnalysis = {duration_s, fps, canvas, scenes:[{start,end}], shot_stats:{count, mean_s, median_s, cuts_per_min, histogram}, motion:{zoom_events, pan_estimate}, audio:{loudness_lufs, speech_ratio, music_detected: bool|null, silence_ratio}, text_on_screen?: [{t, text, bbox}] (si pack ocr), transcript_excerpt?, contact_sheet_path (PNG 4×6 con timestamps), thumbnails:[paths]}`.
- Workers `POST /style/infer {analysis_path, contact_sheet_path}` → `StylePreset` vía Ollama `qwen2.5vl:3b` con `format` = JSON Schema (pack `vision-llm`); si no está → 409 PACK_REQUIRED con texto "o usá la Consola Claude".
- Shared `StylePreset = {id, name, source?: {assetId, analysis_path}, canvas: "16:9"|"9:16"|"1:1", cut_rhythm: {target_shot_s, remove_silences: bool, min_silence_ms}, captions: {style: CaptionStyleId, animated: bool, position}, titles: {template: TemplateId, params}, lower_third?: {...}, transitions: {type, every_n_cuts?}, music: {duck: bool, volume_db}, zoom_punch_in?: {every_s, scale}, ai_label?: bool, export_preset: PresetId, notes_es}` + `compileStylePreset(preset, project) → EditPlan` (determinista, en shared, con tests).
- API: `POST /api/style/analyze {assetId}` (job `style.analyze`, guarda análisis como asset `analysis` + hoja de contactos servida por `/files`), `POST /api/style/infer {analysisId}` (job), `GET/POST /api/style/presets`, `POST /api/style/presets/:id/apply {projectId}` → genera EditPlan con `compileStylePreset` y lo guarda como plan del Asistente (status proposed) → el usuario confirma en el panel Asistente.
- Web: panel "Perfil de estilo": elegir video de referencia (asset) → Analizar → muestra hoja de contactos, ritmo de cortes, audio, textos; botones "Deducir con modelo local" (pack vision-llm) y "Deducir con Consola Claude" (abre la consola y pega el prompt con las rutas); lista de presets guardados; "Aplicar a este proyecto" → abre el plan en el Asistente.

## C. Stems (agente "stems")
Rutas: `apps/workers/studio_workers/audio/stems.py` + `routers/audio.py` (ampliar) + pack `stems` (demucs `htdemucs`, MIT, ~80 MB pesos vía torch hub / URL oficial, torch ya presente), `packages/shared/src/stems.ts`, `apps/api/src/routes/audio.ts` + `jobs/handlers/audio-stems.ts`, `apps/web/src/components/panels/VoicePanel.tsx` (sección "Separar audio") + `stores/stems-store.ts`, `docs/trabajo/modulo-sprint3b-stems.md`.
- Workers `POST /audio/stems {path, mode: "two"|"four", output_base}` → task → `{stems: {vocals, no_vocals} | {vocals, drums, bass, other}, sample_rate}` WAV; GPU budget (≈2 GB) con fallback CPU y aviso; segmentado por tramos (`segment=7` en 6 GB).
- API job `audio.stems {assetId|clipId, mode, target?: {projectId}}` → nuevos assets de audio + pistas "Voz", "Música" (o 4) alineadas al clip origen, pista original silenciada (reversible); 409 PACK_REQUIRED.
- Web: en Voz y audio: "Separar audio" (2 o 4 pistas), progreso, resultado como pistas nuevas; botón "Deshacer separación".

## D. Recorte de calidad alta (agente "recorte")
Rutas: `apps/workers/vision_gpl/**`, `apps/workers/studio_workers/vision/matte.py`, `gpl.py`, entrada de pack `matting-hq` en `packs.py` (solo su bloque), `perf.py` (solo métricas rvm hq), `apps/api/src/jobs/handlers/vision.ts` (solo pasar `quality`), `apps/web/src/components/vision/**` (selector de calidad), `docs/trabajo/modulo-sprint3b-recorte.md`.
- Pack `matting-hq`: RVM resnet50 TorchScript (GPL, mismo venv-gpl) + refinado: `quality: "fast"|"high"`; en `high`: downsample 0,375, resnet50 fp16, post-proceso de alfa (guided filter o erosión + feather configurable), **despill/decontaminación** de bordes (estimar color de fondo por región y neutralizar halos), opción `use_mask` (máscara SAM del clip como guía: alfa fuera de la máscara dilatada = 0).
- Perf: `rvm_hq_steady_fps`; UI muestra ambos.
- Web: en "Quitar fondo": selector Rápido / Alta calidad, deslizadores de borde (suavizado, erosión), casilla "usar máscara SAM si existe", vista previa antes/después de un fotograma.

## E. Compositor de capas (agente "capas")
Rutas: `packages/shared/src/timeline.ts` (campos nuevos de Clip/Track: `blendMode`, `maskRef`, `opacity` ya existe), `apps/api/src/services/ffmpeg/{timeline,builders,keyframe-expr}.ts` + tests, `apps/web/src/lib/compositor.ts`, `apps/web/src/components/preview/**`, `apps/web/src/components/panels/InspectorPanel.tsx`, `apps/web/src/components/timeline/**` (reordenar pistas), `docs/trabajo/modulo-sprint3b-capas.md`.
- Shared: `Clip.blendMode?: "normal"|"multiply"|"screen"|"overlay"|"add"|"difference"|"lighten"|"darken"`, `Clip.maskRef?: {type:"asset", assetId} | {type:"shape", shape:"rect"|"ellipse", x,y,w,h, feather, invert}`, `Track.order` (z-order explícito), `Track.visible/locked` ya existen.
- Export: cualquier clip de una pista de video superior se compone sobre la mezcla inferior con transformación, opacidad, keyframes, `blend=all_mode=…` cuando `blendMode ≠ normal`, máscara (`alphamerge` con asset o máscara geométrica generada con `geq`/`drawbox`+`gblur` para feather); orden por `Track.order`; hash del segment cache incluye todo; tests de píxeles para multiply/screen y máscara elíptica.
- Preview: mismo orden y `globalCompositeOperation` equivalente; máscara con `clip()`/`destination-in` y feather aproximado; paridad con test de píxel.
- Web: Propiedades → sección "Capa": modo de fusión, máscara (ninguna / rectángulo / elipse / máscara SAM) con editor de forma sobre la preview, botón "Invertir"; arrastrar pistas para reordenar (z-order); menú "Mover arriba/abajo".

## Criterios del sprint
Consola: `claude` corre dentro de Studio y una herramienta MCP (`studio_get_project`) responde desde la consola en la PC del usuario. Estilo: análisis de un video de 1 min < 60 s en CPU; preset aplicado genera un EditPlan válido. Stems: 1 min de audio < 60 s en GPU. Recorte HQ: halos visiblemente menores que en Rápido en un clip con fondo colorido (comparativa en docs). Capas: multiply/screen y máscara elíptica idénticos entre preview y export (test de píxeles).
